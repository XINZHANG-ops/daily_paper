SwanTale: Unified Multi-Speaker Speech and Audio Generation for Instruct and Zero-Shot Tasks

Published: 2026-08-02

Link: http://arxiv.org/pdf/2608.02023

1. 📘 Topic and Domain: This paper focuses on unified multi-speaker speech and audio generation within the speech synthesis and audio generation domain, specifically supporting both caption-conditioned instruct tasks and reference-audio-conditioned zero-shot tasks in media production scenarios.
2. 💡 Previous Research and New Ideas: Building upon prior zero-shot TTS systems (e.g., CosyVoice, F5TTS, SwanVoice) and instruction-following TTS systems (e.g., Parler-TTS, VoxInstruct), SwanTale introduces the new idea of unifying both paradigms in a single model while jointly generating speech, environmental audio, and local audio effects through novel components including SwanData-Caption, SwanVAE, and Unified MoE.
3. ❓ Problem: The paper addresses the open problem of supporting both long-form multi-speaker zero-shot synthesis and highly expressive instruct-style speech generation—with environment descriptions, speaker personas, fine-grained content, and audio effects—in a single unified model.
4. 🛠️ Methods: The paper proposes a four-stage data pipeline (SwanData-Caption), a 48 kHz waveform-latent autoencoder (SwanVAE), a flow-matching DiT with reward-conditioned quality control and Engram memory conditioning, a Unified MoE with task and audio routers using dynamic Top-P routing, curriculum learning, and Flow-GRPO post-training.
5. 📊 Results and Evaluation: SwanTale leads on multiple key zero-shot and instruct metrics, achieves the best expressiveness scores in both tasks (e.g., 0.95 Timbre Consistency, 3.90 Richness, 4.22 Mean MOS on SwanBench-Scene), and successfully supports complex instruct generation involving multi-speaker speech and audio.
1. 📘 主题与领域: 本文聚焦于语音合成与音频生成领域的多说话人语音与音频统一生成，专门支持媒体制作场景下基于字幕描述的指令式任务和基于参考音频的零样本任务。
2. 💡 先前研究与新思路: 在先前零样本TTS系统（如CosyVoice、F5TTS、SwanVoice）和指令跟随TTS系统（如Parler-TTS、VoxInstruct）的基础上，SwanTale引入了将两种范式统一于单一模型、并通过SwanData-Caption、SwanVAE和Unified MoE等新组件同时生成语音、环境音和局部音效的新思路。
3. ❓ 问题: 本文解决了在单一统一模型中同时支持长格式多说话人零样本合成和高度表现力指令式语音生成（包括环境描述、说话人角色、细粒度内容和音效）的开放性问题。
4. 🛠️ 方法: 本文提出了四阶段数据流水线（SwanData-Caption）、48 kHz波形-潜空间自编码器（SwanVAE）、具有奖励条件质量控制和Engram记忆条件的流匹配DiT、采用任务路由器和音频路由器及动态Top-P路由的Unified MoE、课程学习以及Flow-GRPO后训练方法。
5. 📊 结果与评估: SwanTale在多项关键的零样本和指令式指标上领先，在两个任务中均取得最佳表现力分数（例如音色一致性0.95、丰富度3.90、SwanBench-Scene平均MOS 4.22），并成功支持涉及多说话人语音和音频的复杂指令式生成。

LongHorizon-Harness: Advancing Long-Horizon Agents for Real-World Tasks

Published: 2026-08-02

Link: http://arxiv.org/pdf/2608.01964

1. 📘 Topic and Domain: The paper focuses on advancing long-horizon LLM-based agents for real-world computer-use and command-line tasks, situated in the domain of AI agent systems, agent harnesses, and autonomous task execution. 2. **💡 Previous Research and New Ideas:** It builds on existing agent frameworks (Claude Code, Codex CLI, OpenClaw) and frontier models, while introducing the new idea of reformulating long-horizon execution as an explicit task-state management problem with independently verified state transitions rather than a single growing trajectory. 3. **❓ Problem:** It addresses compounding errors, context rot, and task-state loss in long-horizon agent execution, where existing harnesses conflate task execution, state management, and self-assessment within a shared growing context, causing incorrect judgments to propagate. 4. **🛠️ Methods:** The paper proposes LongHorizon-Harness with a Manage-Execute-Audit (MEA) loop, where a manager maintains explicit task state and constructs bounded subtask contracts, a fresh-context executor performs subtasks, and a read-only auditor independently verifies environment state, all supported by a lightweight AgentAdapter for interchangeable backends. 5. **📊 Results and Evaluation:** LongHorizon-Harness raises Qwen 3.7-Plus from 51.8% to 80.7% on WeaveBench, 69.7% to 77.2% on Terminal-Bench 2.1, and 2.8% to 8.3% on OSWorld 2.0, while also improving Claude Opus 4.7 from 20.0% to 34.3% on an OSWorld 2.0 subset, demonstrating consistent gains across models, harnesses, and interaction domains.

Progressive Agent Skill Generation via Reinforcement Learning

Published: 2026-08-02

Link: http://arxiv.org/pdf/2608.01678

1. 📘 Topic and Domain: This paper focuses on LLM agent skill generation, proposing a reinforcement learning framework called Skill-α for automatically producing high-quality procedural skills for agents from heterogeneous evidence sources (documents or execution experience).
2. 💡 Previous Research and New Ideas: The paper builds on prior skill generation methods that rely on heuristics or pipeline-style consolidation (e.g., Ctx2Skill, AutoSkill, Trace2Skill, ExpeL, AWM, SkillX, SkillPro) and on RL techniques for LLM agents (particularly GRPO). The new idea is to formulate skill generation as a progressive sequential editing process and introduce a "rollback reward" that provides execution-grounded credit assignment for local edits, unifying document-to-skill and experience-to-skill under one learned policy.
3. ❓ Problem: The paper addresses the lack of a natural supervision signal for evaluating skill quality—unlike factual or tool-use outputs, a skill's value can only be determined by whether it improves the agent's downstream task performance—and the fact that existing methods require separately designed pipelines for different evidence sources, preventing a unified learning-based approach.
4. 🛠️ Methods: Skill-α decomposes skill construction into a sequence of local edit actions (CREATE, UPDATE, MERGE, PRUNE, NOOP) conditioned on current skill state and evidence, trained via GRPO. The key training signal is a rollback reward that compares worker execution under the original versus edited skill on the same evidence-anchored query, assigning credit at the edit level rather than the full-trajectory level.
5. 📊 Results and Evaluation: Under the GPT-4o worker, Skill-α improves average downstream success rates by 3.3 points on CL-Bench and 6.7 points on tau2-bench over the strongest baselines, and also achieves the best or tied-best results on SpreadsheetBench. Skills transfer effectively to Claude-Sonnet-4.5 as a different worker. Ablations confirm that both rollback reward and the full edit action space (including MERGE/PRUNE/NOOP) are critical components.
1. 📘 主题与领域: 本文聚焦于大语言模型智能体的技能生成（agent skill generation）领域，提出了一种基于强化学习的 Skill-α 框架，用于从文档或执行经验等异构证据源中自动生成高质量的智能体可复用技能。
2. 💡 先前研究与新思路: 本文基于已有的启发式或流水线式技能生成方法（如 Ctx2Skill、AutoSkill、Trace2Skill、ExpeL、AWM、SkillX、SkillPro）以及面向 LLM 智能体的强化学习技术（尤其是 GRPO）。其新思路在于：将技能生成建模为一个渐进的序列编辑过程，并提出"回滚奖励"（rollback reward）为局部编辑提供基于执行效果的信用分配，从而在统一的习得策略下同时支持文档生成技能与经验生成技能两种场景。
3. ❓ 问题: 论文解决了技能质量缺乏自然监督信号的问题——技能的价值不像事实性或工具调用输出那样可被直接评估，只能通过其对智能体下游任务表现的影响来判断；以及现有方法针对不同证据源需设计独立流水线、缺乏统一学习框架的问题。
4. 🛠️ 方法: Skill-α 将技能构建分解为一系列基于当前技能状态和证据的局部编辑动作（CREATE、UPDATE、MERGE、PRUNE、NOOP），并通过 GRPO 进行训练。其核心训练信号是回滚奖励——在相同的证据相关锚定查询上比较智能体在原始技能与编辑后技能下的执行效果，从而实现编辑级别的（而非整条轨迹级别的）信用分配。
5. 📊 结果与评估: 在 GPT-4o 作为工作智能体时，Skill-α 在 CL-Bench 上的平均下游成功率较最强基线提升 3.3 个百分点，在 tau2-bench 上提升 6.7 个百分点，并在 SpreadsheetBench 上达到最佳或并列最佳水平；所生成的技能还能有效迁移到 Claude-Sonnet-4.5 作为不同工作智能体的场景。消融实验进一步证明回滚奖励和包含 MERGE/PRUNE/NOOP 的完整编辑动作空间均为关键组件。

Today's Reading Tips 今日阅读推荐

Start with LongHorizon-Harness—its Manage-Execute-Audit loop and explicit task-state reformulation provide a clean architectural idea with striking empirical gains (e.g., 51.8% to 80.7% on WeaveBench), making it broadly useful for anyone building agents. Then read Skill-α, which is highly complementary: its rollback-reward RL approach for generating procedural skills can naturally plug into harnesses like LongHorizon to further boost downstream task performance. SwanTale is more domain-specific (unified speech/audio generation) and can be read independently based on your interest in TTS and audio modeling.
建议先读 LongHorizon-Harness——其 Manage-Execute-Audit 循环与显式的任务状态重构思路提供了一个清晰的架构范式，且实证提升显著（如 WeaveBench 从 51.8% 提升至 80.7%），对任何在做智能体系统的研究者都有参考价值。紧接着读 Skill-α，它与前者高度互补：基于回滚奖励的强化学习技能生成方法，可自然嵌入类似 LongHorizon 的执行框架，进一步提升下游任务表现。SwanTale 方向更专（统一语音/音频生成），可按对 TTS 与音频建模的兴趣独立阅读。
