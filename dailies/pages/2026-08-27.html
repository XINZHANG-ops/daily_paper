VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction

Published: 2026-08-25

Link: http://arxiv.org/pdf/2608.26005

1. 📘 Topic and Domain: The paper focuses on building a streaming, dual-brain memory architecture (informational + emotional) for real-time duplex speech language models (SLMs), bridging conversational AI, memory systems, and affective computing.
2. 💡 Previous Research and New Ideas: It builds on prior memory engines (Mem0, Zep, LangMem, A-MEM, MemoryOS, MemOS, EverMemOS) and emotion-aware retrieval (Emotional RAG, KEEM), introducing the novel idea of separating factual information ("left brain") from emotional/persona modeling ("right brain") and tightly coupling them with a streaming, low-latency retrieval pipeline.
3. ❓ Problem: The paper addresses the lack of an integrated memory system for real-time voice agents that can handle three challenges: (O1) unifying informational and emotional intelligence, (O2) achieving high information density under near-zero latency (top-5 retrieval within ~134 ms), and (O3) remaining simple, evolvable, and decoupled from rapidly changing backends and SLMs.
4. 🛠️ Methods: The authors propose VOICEMEM with (i) a left-brain schema–entity index with a query-driven cluster emergence mechanism, (ii) a right-brain persona graph with independent and cross-entity nodes plus short/long-horizon emotion attribution, (iii) a four-stage streaming retrieval (listening → speech tail → anticipation → searching) fitting inside the VAD window, (iv) a decoupled graph-on-graph architecture with interchangeable memory backends, and (v) an SLM-verified black-box OPD training pipeline producing CHATMEM-400K and the CHATMEM-BENCH benchmark.
5. 📊 Results and Evaluation: VOICEMEM achieves 76.39 average on information memory (+24.12 over Mem0), 74.16/76.56 on persona memory (+1.89 over previous SOTA MemOS), and 68.73 on CHATMEM-BENCH leading 11/14 categories, while retrieving 91.2 on LoCoMo with only 430 tokens and 134 ms latency; ablations confirm every component contributes, and the index transfers across backends yielding +15.8 to +29.5 point gains.
1. 📘 主题与领域: 论文聚焦于为实时双工语音语言模型（SLM）构建一种流式、双脑（信息+情感）的记忆架构，跨越对话式AI、记忆系统与情感计算领域。
2. 💡 先前研究与新思路: 基于现有记忆引擎（Mem0、Zep、LangMem、A-MEM、MemoryOS、MemOS、EverMemOS）及情感感知检索（Emotional RAG、KEEM），其新思路是将事实信息（"左脑"）与情感/人设建模（"右脑"）分离，并通过流式低延迟检索管线紧密耦合二者。
3. ❓ 问题: 论文解决了实时语音助手缺乏统一记忆系统的难题，需同时应对三大挑战：(O1) 统一信息与情感智能；(O2) 在近乎零延迟（134 ms内top-5检索）下保持高信息密度；(O3) 架构需简洁、可演进，并与快速迭代的后端和SLM解耦。
4. 🛠️ 方法: 作者提出VOICEMEM，包括：(i) 左脑的schema–entity二级索引与查询驱动的聚类涌现机制；(ii) 右脑的独立与跨实体persona节点，结合短/长期情感归因；(iii) 听音→尾音→预判→搜索的四阶段流式检索，嵌入VAD时间窗内；(iv) 解耦的"图上图"架构支持可替换记忆后端；(v) 基于SLM验证的黑箱OPD训练流程，产出CHATMEM-400K训练集与CHATMEM-BENCH评测基准。
5. 📊 结果与评估: VOICEMEM在信息记忆任务上平均达到76.39（较Mem0提升+24.12），在persona任务上达74.16/76.56（较此前最佳MemOS提升+1.89），在CHATMEM-BENCH的14个细类中领先11个，且仅用430 token和134 ms检索延迟即在LoCoMo上取得91.2分；消融实验证明各模块均有效，索引可跨后端迁移，带来+15.8至+29.5分的提升。

JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution

Published: 2026-08-25

Link: http://arxiv.org/pdf/2608.25593

1. 📘 Topic and Domain: The paper focuses on agent harness intelligence for LLM-based AI agents, specifically in the domain of agentic system design and optimization.
2. 💡 Previous Research and New Ideas: It builds on prior work in agent harness engineering (Claude Code, Codex, MemEvolve, etc.) and Ahead-of-Time (AOT) harness optimization (Meta-Harness, AHE, Harness-R1). The new idea is the Just-in-Time (JIT) paradigm, where a trained meta-model synthesizes task-conditioned harnesses on the fly, shifting from optimizing durable artifacts to native JIT synthesis.
3. ❓ Problem: The paper addresses the problem that harness design remains manual, task-specific, and unscalable, and that AOT-optimized harnesses struggle to generalize across heterogeneous, instance-dependent task demands, making agent capability dependent on brittle model-harness pairings.
4. 🛠️ Methods: The paper proposes JIT-Agent, a 27B meta-model trained through a three-stage pipeline: (1) Stage I for task-conditioned harness customization via SFT and preference learning over a four-module protocol (memory, planning, action, capability orchestration); (2) Stage II for repairing failed harnesses using execution diagnostics; (3) Stage III for online evolution via Evolutionary Group-Decoupled Policy Optimization (Evo-GDPO), supported by HarnessFactory, a unified codebase of 13 seed harnesses.
5. 📊 Results and Evaluation: JIT-Agent consistently improves backbones across 9 benchmarks (e.g., GLM-5.2 average rises from 74.1 to 81.8, +7.7; DeepSeek-V4-Flash from 66.7 to 75.5, +8.8), achieves competitive performance with frontier models (DeepSeek-V4-Flash + JIT surpasses GPT-5.6 on DeepSearchQA by +9.1), and reduces per-case API cost by 14.9–54.1% compared to fixed harnesses like Claude Code, OpenCode, and NanoBot, while generalizing across DeepSeek V4, Qwen3.6, and Mimo-V2.5 model families.
1. 📘 主题与领域: 论文聚焦于基于大语言模型的AI智能体的智能体框架（harness）设计，属于智能体系统工程与优化领域。
2. 💡 先前研究与新思路: 研究建立在现有智能体框架工程（Claude Code、Codex、MemEvolve等）和事前优化（AOT）框架方法（Meta-Harness、AHE、Harness-R1）的基础上；新思路是提出即时（JIT）范式，让训练好的元模型按需动态生成任务适配的框架，将框架构造从优化持久化产物转变为原生的即时合成。
3. ❓ 问题: 论文解决了智能体框架设计依赖人工、任务专属且难以扩展的问题，以及事前优化的框架难以泛化到异构、实例相关的任务需求的问题，使得智能体能力受限于脆弱的模型-框架配对。
4. 🛠️ 方法: 论文提出了JIT-Agent，一个270亿参数的元模型，通过三阶段流程训练：(1) 第一阶段通过SFT和偏好学习在四模块协议（记忆、规划、动作、能力编排）上学习任务条件化的框架定制；(2) 第二阶段利用执行诊断信息修复失败框架；(3) 第三阶段通过进化式分组解耦策略优化（Evo-GDPO）实现在线进化，并以包含13个种子框架的统一代码库HarnessFactory为支撑。
5. 📊 结果与评估: JIT-Agent在9个基准上持续提升基座模型性能（如GLM-5.2平均分从74.1升至81.8，+7.7；DeepSeek-V4-Flash从66.7升至75.5，+8.8），与前沿模型具备竞争力（DeepSeek-V4-Flash + JIT在DeepSearchQA上超越GPT-5.6达+9.1），相比Claude Code、OpenCode、NanoBot等固定框架将每案例API成本降低14.9%–54.1%，并能跨DeepSeek V4、Qwen3.6和Mimo-V2.5模型系列泛化。
