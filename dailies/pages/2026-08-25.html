Paper 1

Apodex 1.1: Scaling Agentic Intelligence for Complex Work

Published: 2026-08-23

Link: http://arxiv.org/pdf/2608.23283

1. 📘 Topic and Domain: The paper presents Apodex 1.1, a general-purpose language model and execution system in the AI/ML domain that scales agentic intelligence for long-horizon, complex professional work involving files, code, search, and multi-agent coordination.
2. 💡 Previous Research and New Ideas: Building on prior work such as ReAct (reasoning-action loops), Toolformer (learned tool use), multi-agent frameworks (AutoGen, MetaGPT, ChatDev), executable environment benchmarks (WebArena, OSWorld, SWE-bench, APEX-Agents), and agentic RL methods (Search-R1, RAGEN, DAPO), the paper's new idea introduces two explicit complementary scaling dimensions—Environment Scaling (expanding executable file, search, and code worlds) and Agentic Coordination Scaling (expanding how work is organized across agents and time)—connected through a common execution harness and AgentOS runtime.
3. ❓ Problem: The paper addresses the gap between high-quality reasoning in language models and their ability to sustain reliable, verifiable work over long horizons, including file handling, code execution, state maintenance, failure recovery, multi-agent coordination, and delivery of checkable artifacts in professional, scientific, and financial domains.
4. 🛠️ Methods: The paper uses a unified task contract formalism, Environment Scaling across File/Search/Code worlds with independent verification and replay, an Agent Team architecture with an explicit task board, asynchronous human intervention, asymmetric verification, adaptive Max Team Effort, and evidence-grounded synthesis, an AgentOS execution substrate with persistent workspace, three-region namespace, single-publisher lease, and tiered compaction, plus unified SFT and agentic RL training (PIVOT-RL for localized trajectory optimization) with failure-driven task construction loops.
5. 📊 Results and Evaluation: Apodex 1.1 with Agent Team reaches 78.8 on GDPVal, 38.5 on APEX-Agents, 54.3 on FrontierFinance, 63.3 on FrontierScience-Research, 35.3 on BioMysteryBench, 56.1 on HLE, 69.1 on FrontierSearchBench, and competitive mathematics results (36.5 on IMO 2025, exceeding the 35 reference threshold), with the 35B mini model reaching the performance band of selected frontier systems, and HDS6 process evaluation showing consistent gains in long-horizon state coherence, evidence fidelity, hypothesis management, and verification behavior.
1. 📘 主题与领域: 该论文介绍了 Apodex 1.1，这是一款通用语言模型与执行系统，属于 AI/ML 领域，旨在为涉及文件、代码、搜索和多智能体协作的长期复杂专业工作扩展智能体能力。
2. 💡 先前研究与新思路: 该研究基于先前工作，如 ReAct（推理-行动循环）、Toolformer（学习工具使用）、多智能体框架（AutoGen、MetaGPT、ChatDev）、可执行环境基准（WebArena、OSWorld、SWE-bench、APEX-Agents）以及智能体强化学习方法（Search-R1、RAGEN、DAPO），其新思路是引入两个明确的互补扩展维度——环境扩展（扩展可执行文件、搜索和代码世界）和智能体协调扩展（扩展工作如何在智能体和时间之间组织），并通过通用执行框架和 AgentOS 运行时将两者连接起来。
3. ❓ 问题: 该论文解决了语言模型高质量推理与在长周期内持续执行可靠工作之间的差距，包括文件处理、代码执行、状态维护、故障恢复、多智能体协作，以及在专业、科学和金融领域中交付可验证成果的能力。
4. 🛠️ 方法: 该论文采用统一任务契约形式化、跨文件/搜索/代码世界的环境扩展（具有独立验证和重放）、智能体团队架构（包含显式任务板、异步人工干预、不对称验证、自适应最大团队投入和基于证据的综合）、AgentOS 执行基础设施（具有持久化工作区、三区域命名空间、单一发布者租约和分层压缩），以及统一 SFT 和智能体强化学习训练（PIVOT-RL 用于局部轨迹优化）和失败驱动的任务构建循环。
5. 📊 结果与评估: 配备 Agent Team 的 Apodex 1.1 在 GDPVal 上达到 78.8，APEX-Agents 上达到 38.5，FrontierFinance 上达到 54.3，FrontierScience-Research 上达到 63.3，BioMysteryBench 上达到 35.3，HLE 上达到 56.1，FrontierSearchBench 上达到 69.1，并在数学竞赛任务上取得有竞争力的结果（IMO 2025 上为 36.5，超过 35 的参考阈值），35B mini 模型达到了所选前沿系统的性能区间，HDS6 过程评估显示在长程状态一致性、证据保真度、假设管理和验证行为方面均有持续改进。

Paper 2

EchoWM: Open and Enterable Omnimodal World Models

Published: 2026-08-23

Link: http://arxiv.org/pdf/2608.23189

1. 📘 Topic and Domain: The paper presents an omnimodal world model (EchoWM) for interactive generative media, situated in the domains of computer vision, generative AI, and audio-visual synthesis, enabling continuous navigation with synchronized generation of 720p video, environmental sound, music, and speech.
2. 💡 Previous Research and New Ideas: The paper builds on prior interactive world models (e.g., Genie, SANA-WM, DreamX-World, Matrix-Game) and joint audio-visual generators (e.g., LTX-2, Cosmos 3, Veo 3). Its new idea is introducing an "enterable omnimodal world" concept that unifies first-person and third-person interaction through a single camera-intent interface based on a shared relative 6-DoF trajectory with dataset-level metric calibration.
3. ❓ Problem: The paper addresses the lack of world models that jointly support continuous user navigation, synchronized audio-visual generation (video, environmental sound, speech), and consistent long-horizon interaction across both first-person and third-person perspectives in general and game scenes.
4. 🛠️ Methods: The method combines a four-source world data engine (internal gameplay, human-played internet gameplay, UE simulation, general internet video) with three stage-aligned data mixtures, a unified camera-intent interface with global translation scale calibration, relative UCPE-based trajectory conditioning, a four-stage progressive training curriculum (AV-CPT, Action-SFT, Joint-FT, AR post-training), and audio-visual teacher forcing with short- and long-horizon Self-Gradient Forcing using a sink-plus-FIFO KV cache.
5. 📊 Results and Evaluation: EchoWM ranks first on WBench Navigation with an Average score of 81.7, achieves the highest VBench Overall on SANA-WM-Bench (83.91 on Simple, 83.96 on Hard splits), and its distilled four-step variant EchoWM-Flash attains the best VBench Overall among causal models (80.13/81.06); user studies show 46.50% and 63.13% overall preference over LingBot-World-v2 and HappyOyster, respectively.
1. 📘 主题与领域: 论文提出了一个用于交互式生成媒体的全模态世界模型（EchoWM），属于计算机视觉、生成式AI和音视频合成领域，支持持续导航并同步生成720p视频、环境音、音乐和语音。
2. 💡 先前研究与新思路: 论文基于先前的交互式世界模型（如Genie、SANA-WM、DreamX-World、Matrix-Game）和联合音视频生成模型（如LTX-2、Cosmos 3、Veo 3），其新思路是提出"可进入的全模态世界"概念，通过基于共享相对6自由度轨迹和数据集级度量标定的单一相机意图接口，统一第一人称和第三人称交互。
3. ❓ 问题: 论文解决了现有世界模型无法同时支持持续用户导航、同步音视频生成（视频、环境音、语音）以及在通用和游戏场景中跨第一/第三人称视角保持长时一致性的问题。
4. 🛠️ 方法: 方法结合了四源世界数据引擎（内部游戏、人类游玩网络游戏、UE仿真、通用网络视频）与三级数据混合、统一的相机意图接口与全局平移尺度标定、基于相对UCPE的轨迹条件注入、四阶段渐进式训练（AV-CPT、Action-SFT、Joint-FT、AR后训练），以及采用sink-plus-FIFO KV缓存的音视频教师强制和短/长时自梯度强制（SGF）。
5. 📊 结果与评估: EchoWM在WBench Navigation上以81.7的平均分排名第一，在SANA-WM-Bench上取得最高VBench Overall（简单轨迹83.91，困难轨迹83.96），其四步蒸馏版EchoWM-Flash在因果模型中取得最佳VBench Overall（80.13/81.06）；用户研究显示其总体偏好度分别超过LingBot-World-v2和HappyOyster 46.50%和63.13%。

MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks

Published: 2026-08-23

Link: http://arxiv.org/pdf/2608.23035

1. 📘 Topic and Domain: The paper introduces MobilePA-Bench, a benchmark for evaluating LLM-based mobile planner agents on complex, tool-centric, real-world tasks within mobile operating systems.
2. 💡 Previous Research and New Ideas: It builds on prior GUI-centric benchmarks (e.g., AndroidWorld, OSWorld) and static function-calling benchmarks (e.g., BFCL, DroidCall, TAU-Bench), proposing the new idea of an interactive, stateful, tool-centric benchmark that unifies structured API orchestration, sub-agent delegation, memory retrieval, and skill usage.
3. ❓ Problem: It addresses the critical blind spot that existing benchmarks either focus only on surface-level GUI manipulation or rely on offline API matching, failing to evaluate a mobile planner's ability to handle real runtime constraints, long-horizon planning, and background tool use.
4. 🛠️ Methods: The paper constructs a stateful mobile simulation sandbox with 1,705 tasks, 212 tools, and 13 functional domains, evaluating four capability dimensions (Basic Tool Use, Sub-agent Collaboration, Memory Usage, and Skill Usage) using three evidence-aligned query buckets (Tool Call, State Change, Agent Behavior) for verification.
5. 📊 Results and Evaluation: Experiments on 13 frontier LLMs show that even the best model (Claude-Opus-5) achieves only 75.52% overall, with sharp performance drops under strict tool ordering, permission limits, runtime errors, and sub-agent coordination, while no single model dominates across all capability dimensions.
1. 📘 主题与领域: 该论文介绍了 MobilePA-Bench，一个用于评估基于 LLM 的移动规划智能体在移动操作系统中完成复杂、工具化、真实世界任务的基准测试。
2. 💡 先前研究与新思路: 该研究基于先前的 GUI 中心基准（如 AndroidWorld、OSWorld）和静态函数调用基准（如 BFCL、DroidCall、TAU-Bench），提出了交互式、有状态、以工具为中心的新基准，统一了结构化 API 编排、子智能体委派、记忆检索和技能使用。
3. ❓ 问题: 该研究解决了现有基准的盲点：它们要么仅关注表层 GUI 操作，要么依赖离线 API 匹配，无法评估移动规划智能体在真实运行时约束、长期规划和后台工具使用方面的能力。
4. 🛠️ 方法: 该论文构建了一个有状态的移动模拟沙盒，包含 1,705 个任务、212 个工具和 13 个功能领域，使用三个证据对齐的查询桶（工具调用、状态变化、智能体行为）评估四个能力维度（基础工具使用、子智能体协作、记忆使用和技能使用）。
5. 📊 结果与评估: 对 13 个前沿 LLM 的实验表明，即使是最佳模型（Claude-Opus-5）的总体得分也仅为 75.52%，在严格工具排序、权限限制、运行时错误和子智能体协调下性能急剧下降，且没有单一模型在所有能力维度上均占优势。

Today's Reading Tips 今日阅读推荐

Start with Apodex 1.1 (Paper 1) for the broadest systems-level perspective on long-horizon agentic intelligence, then follow up with MobilePA-Bench (Paper 3)—they form a natural pair, as the benchmark explicitly highlights the tool-orchestration and sub-agent coordination gaps that systems like Apodex aim to address. EchoWM (Paper 2) is a standalone topic on omnimodal world models and can be read independently based on your interest in generative media.
建议先阅读 Apodex 1.1（论文 1），它从系统层面最全面地阐述了长周期智能体的设计；再读 MobilePA-Bench（论文 3），这两篇高度互补——该基准正揭示了 Apodex 这类系统所要解决的多工具编排与子智能体协调难题。EchoWM（论文 2）属于多模态世界模型方向，可根据你对生成式媒体的兴趣独立阅读。
